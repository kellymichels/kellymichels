### Public here

**[evo.zscripts](https://github.com/evomedia-net/evo.zscripts)** — one-word commands for multi-project development, built for the case where an AI agent would otherwise burn its context window on SSH plumbing and Docker output. `zdeploy myapp`, `zrepair myapp`, `zstart myapp`. Measured at ~26,500 tokens saved per active development day. Tested under Pester.

**[evo.locate](https://github.com/evomedia-net/evo.locate)** — self-hosted IP geolocation. No account, no API key, no per-query cost, and no visitor IP ever leaves the machine. Drop-in for ip2location's free tier: same JSON field names, repoint the URL. Built after pricing the paid options and realising a 140 MB file answers the question.

Both exist for the same reason: I would rather build the small thing than rent it, when building removes a dependency, a cost, and a privacy problem at once.
